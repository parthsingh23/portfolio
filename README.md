# Parth Singh Portfolio

Personal portfolio website built with Next.js and TypeScript.

## Live

https://parth-sh.vercel.app/

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide
- Vercel

## Features

- Responsive design
- Light and dark theme
- Project showcase
- Skills overview
- Contact section
- Mobile navigation

## Sections

- Hero
- Projects
- About
- Skills
- Contact
